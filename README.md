# Apkdown

A simple command line tool to download APKs.

Currently this can only download APKs from [Apkpure](https://apkpure.com/), but other providers
may be supported in the future.

## Installation

No release yet, so you have to install from source:

```sh
cargo install --git https://codeberg.org/fieryhenry/apkdown
```

## Usage

See help:

```sh
apkdown --help
```
